01 — Drop

Core gameplay

Every drop changes the board.

Aim, release, and let physics take over. Space is limited, so one small decision can open a chain—or end the run.

02 — Merge

Gameplay

Watch a universe take shape.

Simple input meets lively 2D physics. The rules are immediate; the board that emerges is different every time.
